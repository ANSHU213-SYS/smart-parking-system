# Smart Parking System

## Project Description
A beginner-friendly Arduino-based smart parking system using an ultrasonic sensor and servo motor.

## Components Used
- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- SG90 Servo Motor
- Red LED
- 220-ohm Resistor

## Working
- When a car is detected within 20 cm, the gate opens and the LED turns ON.
- When no car is detected, the gate closes and the LED turns OFF.

## Software
- Wokwi Simulator
- Arduino IDE

## Project Level
Beginner - First Year ECE
